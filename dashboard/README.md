# TraceMind AI Dashboard

Multi-page Streamlit dashboard for incident investigation and root cause analysis.

## Pages

1. **🏠 Overview** (`app.py`) - Incident overview with key metrics, timeline summary, affected services, and leading hypothesis
2. **📅 Timeline** (`pages/2_Timeline.py`) - Detailed incident timeline with deployments, anomalies, errors, and recovery events
3. **🕸️ Causal Graph** (`pages/3_Causal_Graph.py`) - Interactive causal graph showing service dependencies, trace spans, anomalies, and deployment correlations
4. **🔬 Evidence Explorer** (`pages/4_Evidence_Explorer.py`) - Explore logs, spans, metrics, and deployments correlated to the incident
5. **📋 RCA Report** (`pages/5_RCA_Report.py`) - Root cause analysis report with hypothesis ranking, impact radius, and remediation with approval workflow

## Quick Start

### Prerequisites

- Python 3.11+
- Run the Phase 1 simulator first to generate ground truth data

### Installation

```bash
# From the repository root
pip install -r requirements.txt
```

### Run the Dashboard

```bash
# From the repository root
streamlit run dashboard/app.py
```

The dashboard will open at http://localhost:8501

### Generate Test Data

Before running the dashboard, generate the synthetic incident data:

```bash
# Start services (Docker)
docker compose up --build -d

# Wait for services to be healthy, then run scenario
python -m simulator.run_scenario

# Or run without Docker
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export DB_BACKEND=simulated
export OTEL_ENABLED=false
uvicorn services.api_gateway.app:app --port 8000 &
uvicorn services.order_service.app:app --port 8001 &
uvicorn services.payment_service.app:app --port 8002 &
uvicorn services.user_service.app:app --port 8003 &
python -m simulator.run_scenario
```

## Dashboard Features

### Page 1: Incident Overview
- Key metrics (error rate, latency, request counts)
- Incident timeline summary
- Affected services with root cause highlighted
- Leading hypothesis with confidence
- Quick navigation to other pages

### Page 2: Timeline
- Interactive Plotly timeline chart
- Event filtering by type (deployments, anomalies, errors, recovery)
- Detailed event cards with metadata
- Metrics time series (latency, error rate, DB pool usage)
- Export timeline as JSON

### Page 3: Causal Graph
- Interactive NetworkX graph via streamlit-agraph
- Hierarchical and force-directed layouts
- Node types: Services, Deployments, Anomalies, Errors
- Edge types: CALLS, DEPLOYED_TO, OBSERVED_DURING, GENERATED, PRECEDED, SUPPORTS_HYPOTHESIS
- Path analysis from deployment to errors
- Graph statistics and legend
- Export as GraphML

### Page 4: Evidence Explorer
- **Logs Tab**: Structured JSON logs with filtering by service, level, event type, and search
- **Spans Tab**: OpenTelemetry spans with flame graph view for trace correlation
- **Metrics Tab**: Time series and heatmap views for latency, error rate, pool usage
- **Deployments Tab**: Deployment records with incident correlation analysis
- Export all evidence as JSON

### Page 5: RCA Report
- Ranked hypothesis list with scoring factors (temporal, dependency, error, metric, change)
- Factor breakdown visualization
- Impact radius with service health visualization
- Remediation playbook with preconditions, action, risks, verification
- Human approval workflow (Approve/Reject/Execute)
- Evaluation metrics (detection latency, accuracy, MTTR)
- Export as JSON or Markdown

## Data Sources

The dashboard reads from synthetic data generated by the Phase 1 simulator:
- `data/synthetic/scenario_ground_truth.json` - Incident ground truth
- `data/synthetic/deployments.csv` - Deployment records
- `data/synthetic/incident_scenarios.json` - Scenario definitions

Sample logs, spans, and metrics are generated dynamically for demonstration.

## Configuration

Create `.streamlit/config.toml` for custom theming:

```toml
[theme]
primaryColor = "#1f77b4"
backgroundColor = "#ffffff"
secondaryBackgroundColor = "#f0f2f6"
textColor = "#262730"
font = "sans serif"
```

## Extending the Dashboard

### Adding a New Page

1. Create a new file in `pages/` with a number prefix (e.g., `6_New_Page.py`)
2. Use `st.set_page_config()` at the top
3. Implement the page logic
4. Add navigation buttons to other pages

### Connecting Real Data

Replace the sample data generators in each page with real data sources:
- Jaeger/Tempo API for traces
- Loki/OpenSearch for logs
- Prometheus API for metrics
- GitHub/GitLab API for deployments/commits
- PostgreSQL for incident history

## Troubleshooting

### ModuleNotFoundError: streamlit_agraph
```bash
pip install streamlit-agraph
```

### Port already in use
```bash
streamlit run dashboard/app.py --server.port 8502
```

### No data showing
Ensure you've run the simulator:
```bash
python -m simulator.run_scenario
```
